# Орбита

Личный календарь для учёбы и дел вне неё. Из плана можно назначить шаг на конкретную дату. Из свободного дня можно выбрать незавершённый шаг, а затем отметить его выполненным в повестке. Дедлайны, события и ежегодные дни рождения добавляются прямо в календарь.

## Запуск в PowerShell

Проверено на Windows с Node.js 24.14.1, npm 11.11.0 и Python 3.14.4. Выполняйте команды из корня Orbit.

```powershell
npm run setup
npm run seed
npm run dev
```

Откройте [календарь](http://127.0.0.1:5173/calendar). Vite запускается на порту 5173 и проксирует `/api` в FastAPI на порту 8000. [Описание API](http://127.0.0.1:8000/docs).

SQLite по умолчанию хранится в `.data/orbit.sqlite3`. Можно задать другой файл через `ORBIT_DB`. По умолчанию seed использует текущий месяц по локальным часам и сохраняет существующие записи. Для первого показа возьмите отдельный файл и дату из макета. Для повторного прогона с тем же начальным прогрессом укажите новый путь к SQLite.

```powershell
$env:ORBIT_DB = Join-Path $PWD '.data/defense.sqlite3'
npm run seed -- --date 2026-11-20 --flight-plan
npm run dev
```

## Сценарий для защиты

1. Откройте [пятницу, 20 ноября 2026](http://127.0.0.1:5173/calendar?date=2026-11-20&view=day) и включите «Учебные пары». На шкале лекция в аудитории 2403 и консультация пересекаются с 10:00 до 10:30. Карточка «Что дальше» с обратным отсчётом показана на снимках утреннего сценария.
2. Откройте [субботу, 21 ноября 2026](http://127.0.0.1:5173/calendar?date=2026-11-21&view=day). Через «Планы» откройте «Снять первый короткий ролик». Покажите прогресс `1 из 3` и ссылку «Урок по монтажу».
3. Вернитесь кнопкой «Календарь» в верхней панели. Суббота останется выбранной. Нажмите «Выбрать шаг из планов» и выберите «Собрать черновик». Шаг появится в субботней повестке.
4. Перезагрузите страницу, отметьте шаг выполненным и откройте его родительский план по ссылке из повестки. Счётчик покажет `2 из 3`.
5. Откройте [28 ноября](http://127.0.0.1:5173/calendar?date=2026-11-28). «Поездка в Карелию» занимает 27 ноября — 2 декабря одной записью. Нажмите стрелку следующего месяца. В повестке 1 декабря будет «день 5 из 6». Откройте запись и при необходимости измените дату окончания.

На клавиатуре Tab ставит фокус на активную дату. Стрелки перемещают фокус, Enter выбирает день. Любую запись выбранного дня можно открыть из повестки. Escape закрывает диалог и возвращает фокус к кнопке открытия.

## Учебные пары

На календаре включите «Учебные пары». В демонстрационных данных на [27 ноября](http://127.0.0.1:5173/calendar?date=2026-11-27) видны три пары и поездка. Нажмите «3 пары» в ячейке, чтобы открыть повестку с предметами, временем и аудиторией.

Кнопка «Добавить пару» открывает форму. Укажите день недели, время начала и конца, предмет, аудиторию и период семестра. Даты семестра включены в расписание. Из повестки пару можно отредактировать или удалить сразу для всех её повторений. При перезагрузке переключатель снова выключен. Записи о парах остаются в SQLite. Фильтры обычных записей и сводка месяца работают независимо от слоя.

## Неделя, повторы и оформление

Календарь переключается между днём, неделей и месяцем. В дне недельная лента показывает занятость, а карточка «Что дальше» выводит время ближайшего дела, аудиторию пары и ход текущего занятия. В неделе записи с одним временем стоят в одной полосе друг под другом, а пересекающиеся интервалы помечены. На телефоне временные полосы показывают выбранный день недели. Переключатель темы находится в верхней панели. Выбор сохраняется в браузере.

Для события доступны повторы по дням, неделям, месяцам и годам. Серия начинается с выбранной даты. Для 31-го числа месяцы без такого дня пропускаются. Повтор 29 февраля показывается в високосные годы. День рождения автоматически повторяется ежегодно. В окне удаления можно выбрать одно повторение, его вместе со всеми предыдущими, его вместе со всеми следующими или всю серию. Редактирование из окна записи меняет серию целиком.

Галерея разделена на запланированные и выполненные планы. Карточка открывается по всей поверхности. В редакторе можно выбрать рисунок или загрузить PNG, JPEG или WebP до 400 КБ. В деталях порядок шагов меняется перетаскиванием или кнопками вверх и вниз. Удаление плана и шага требует подтверждения, связанные шаги исчезают из календаря.

Пара может быть разовой, еженедельной или проходить раз в две недели. У разовой пары укажите конкретную дату. Для повторяющихся пар можно задать дату первой пары и шаблон семестра. Тип занятия отображается подписью и цветом: лекция, практика, лабораторная или консультация. Границы шаблонов — 1 сентября – 31 декабря и 1 февраля – 31 мая. Даты можно задать вручную.

```powershell
npm run import-schedule
```

Команда добавляет показанные в исходном расписании занятия на 16–29 ноября 2026 года. Повторный запуск сохраняет существующие записи. Продолжительность взята из видимых 90-минутных блоков. Для обрезанного заголовка использована читаемая часть. Бронь помещений исключена. После импорта учебный слой этой базы показывает реальные занятия и пары, добавленные вручную. Учебные примеры seed остаются в базе и продолжают отображаться в отдельной демонстрационной базе без импорта.

## Как использовали AI

- **Макет.** В ТЗ агенту поручили сделать кликабельный HTML, показать два входа в работу с планом и поездку через границу месяца. Первое предложение AI использовало бумажный календарный разворот с повесткой справа. При просмотре 390×844 кнопка добавления уходила на вторую строку, а повестка начиналась слишком низко. Агент уплотнил недели и собрал верхнюю панель в одну строку на этой ширине.
- **Интерфейс.** В запросе перечислили конкретные компоненты Mantine и потребовали одну тему. Проверка Escape выявила потерю фокуса после закрытия формы. Агент восстановил фокус на кнопке открытия и проверил это тестом.
- **Тесты.** ТЗ требовало удерживать POST незавершённым и отдельно воспроизвести двойной клик и повторный Enter. В тесте состояний агент добавил проверку случая, когда сохранение прошло, а обновление календаря завершилось ошибкой. Тест проверяет, что успех виден и повторяется только загрузка списка. В [контрольном прогоне](evidence/session-01-mutation.log) агент временно скрыл ошибку записи. Тест упал на отсутствии сообщения. После восстановления команда для всех тестов прошла.
